# Urban Heat Island Analysis using Land Surface Temperature (LST)

## 📌 Project Overview
This project analyzes spatial temperature variations and Urban Heat Island (UHI) patterns across the target region using Landsat 8 satellite imagery processed through Google Earth Engine (GEE).

## 📊 Result & Visuals
![Land Surface Temperature Map](outputs/lst_map_visual.png)

## 🛠️ Tools & Libraries
* **Platform:** Google Earth Engine (GEE)
* **Python Libraries:** `ee`, `geemap`, `ipywidgets`
* **Dataset:** Landsat 8 Collection 2 Tier 1 Level 2 (`LANDSAT/LC08/C02/T1_L2`)

## 🚀 How to Run
1. Clone this repository: `git clone https://github.com/YOUR_USERNAME/urban-heat-island-lst-analysis.git`
2. Install required dependencies: `pip install earthengine-api geemap ipywidgets`
3. Open and run `notebooks/01_land_surface_temperature.ipynb` in Jupyter Notebook.
